# Kampala Fresh Produce Direct

This is a simple Group A produce cooperative website made with HTML and CSS only. All pages link to one shared external stylesheet.

## Open the website

Open `index.html` in a web browser. The navigation links connect these pages:

- `index.html` — home page
- `about.html` — cooperative background, areas, benefits, mission and vision
- `products.html` — sample product catalogue with category jump links
- `basket.html` — static sample basket and total
- `checkout.html` — delivery form with browser-native required-field and phone format checks
- `confirmation.html` — static sample order confirmation
- `tracking.html` — static example of order status stages

`style.css` contains the shared green-and-cream theme, comments and mobile layout rules. Product prices, basket contents, order reference, tracking status and contact details are examples. The checkout form does not send or save personal information.

Because this version uses only HTML and CSS, the basket cannot add/remove items or recalculate totals, and tracking cannot update automatically. The page content explains which values are samples.
